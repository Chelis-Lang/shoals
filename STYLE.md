# Style

Naming conventions for this repo follow the central Chelis ecosystem style guide:

https://github.com/Chelis-Lang/chelis/blob/main/spec/01-nomenclature.md

Source of truth for filenames, identifiers, module names, function-naming
patterns, and lint rules across the Chelis ecosystem (`chelis`, `nautilus`,
`coral`, `shoals`, `octant`). Adherence is enforced by `chelis lint`.
Local additions to that contract should be proposed there, not duplicated here.
